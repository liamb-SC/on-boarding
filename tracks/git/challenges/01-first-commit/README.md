# 01 · Your first commit

**Skills:** `git add`, `git commit`, `git status`

## Scenario
Your practice repo has been initialised for you. There's one file in the working
directory — `hello.txt` — but it hasn't been committed yet.

## Goal
Stage `hello.txt` and record it as the repository's first commit, leaving a clean
working tree.

## Hints
- `git status` shows what's tracked vs. untracked.
- `git add <file>` stages; `git commit -m "message"` records.
